# Project Notes

This workbench demonstrates a practical way to keep investigation records reproducible and reviewable:

- scope and stop conditions are explicit before collection;
- source lineage, time, capture method, locator, and limitations travel with observations;
- claims cite observations and preserve alternatives and contrary evidence;
- machine suggestions remain proposals while human dispositions are recorded separately;
- a deterministic local validator checks record shape and references;
- the example and test fixture are synthetic, and the default workflow makes no network request.

The command and provenance structure adapts patterns from the author's separate source-compatibility work. The fraud method is the author's existing evidence-led approach; this repository does not claim novelty, measured accuracy, or a validated detection capability. See [`VALIDATION.md`](VALIDATION.md) for what was actually run.
